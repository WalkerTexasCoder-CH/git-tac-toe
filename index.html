Git Tac Toe

One move. One commit. Take turns adding an X or O to the HTML, then share your move with Git.

Make a move in your editor

This is a static board: clicking a square does nothing. Open index.html in your text editor, find an empty cell by its ID, and insert your X or O between its tags. Rows run A to C from top to bottom; columns run 1 to 3 from left to right.

For example: <div class="cell" id="cell-a1">X</div>

Save the file and refresh your browser. Follow the workshop's Git steps to add, commit, and push your move. Pull the latest moves before your next turn.
